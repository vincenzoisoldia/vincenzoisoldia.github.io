This is an example. Files in `_drafts/` are **not** published.
To publish a post, create a file in `_posts/` named like
`2026-10-01-my-title.md` (date first, then the title with dashes).

You can write math: $\chi(S) = 2 - 2g$, or on its own line

$$ \operatorname{Hom}(\pi_1(S), \mathrm{PSL}_n(\mathbb{R})) / \mathrm{PSL}_n(\mathbb{R}) $$

and add images: put them in `images/` and write
![description](/images/profile.jpg)
